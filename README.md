# Project TCABR — Island 2×1

Study and analysis project of data from TCABR, with focus on the investigation of magnetic islands and MHD stability.

## Structure

- `environment.yml` — computational enviroment and dependecie.
- `notes/` — study and reading notes.
- `notebooks/` — computational analisys and experiments.
- `src/` — codes and reusable functions.
- `reports/` — periodic reports on the project.

## Objectives

- Study fundamental MHD stability.
- Comprehend the magnetic diagnosis used in TCABR.
- Learn how to work with MDSplus data.
- Develop tools for data analisys.
- Record in a reproducible way obtained results.
